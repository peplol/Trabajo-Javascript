Du Web - Trabajo Final JavaScript Avanzado

Proyecto realizado por YongJie Du.

Estructura

- index.html: página principal.
- views: páginas internas de galería, presupuesto y contacto.
- css: estilos del sitio.
- js: scripts de JavaScript.
- data: archivo JSON con noticias.
- assets/images: imágenes de la galería.
- assets/icons: iconos de redes sociales del footer.

Funciones principales

- Noticias cargadas desde JSON mediante fetch.
- Galería dinámica con JavaScript.
- Formulario de presupuesto con validación y cálculo automático.
- Mapa dinámico con ruta automática desde la ubicación del usuario hasta la empresa.
